# Stack Operations Using an Array (C)

Array-based stack (SIZE = 5) with push, pop and display.

| File | Purpose |
|---|---|
| `stack.c` | Original program from the assignment |
| `modified.c` | Modified inputs/operations (Q6) |
| `stack_fixed.c` | Improved version fixing the -1 sentinel limitation (Q7) |
| `tests/` | Bodies of 4 extra test programs (Q9) |
| `expected/` | Hand-predicted outputs written before running |
| `run_tests.sh` | Builds everything and diffs actual vs expected |

Run: `sh run_tests.sh` (needs gcc).
